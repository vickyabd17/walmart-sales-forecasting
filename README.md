# Walmart Sales Forecasting & Analysis

## 📌 Problem Statement
A retail chain with multiple stores faces challenges in inventory management due to fluctuating demand. This project aims to analyze historical sales data and forecast future sales.

---

## 📊 Dataset
- Total Records: 6435
- Features: Store, Date, Weekly Sales, Holiday Flag, Temperature, Fuel Price, CPI, Unemployment

---

## 🎯 Objectives
- Analyze sales trends across stores
- Identify factors affecting sales
- Detect seasonality
- Forecast sales for next 12 weeks

---

## 🛠️ Tools & Technologies
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- SARIMA (Time Series)

---

## 🔍 Exploratory Data Analysis
- Sales data is right-skewed with outliers
- Holiday weeks show significant sales spikes
- Variability observed across stores

---

## 📈 Statistical Insights
- Unemployment: Weak correlation with sales
- Temperature: Minimal impact
- CPI: Limited short-term effect

---

## 🔮 Forecasting
- SARIMA model used for time-series forecasting
- Predicted sales for next 12 weeks
- Model performance varies by store

---

## 📊 Results
- Best model: Store 5 (lowest RMSE)
- Worst model: Store 4 (highest RMSE)

---

## 💡 Business Insights
- Sales increase during holidays
- Store-specific strategies required
- Forecasting helps inventory planning

---

## 🚀 Conclusion
This project demonstrates end-to-end data analysis and forecasting using real-world retail data.
